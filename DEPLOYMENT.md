## 🚀 Deploy on Render (Step-by-Step)

### **Step 1: Connect Repository**
1. Go to [Render Dashboard](https://dashboard.render.com/)
2. Click **"New +"** button → Select **"Web Service"**
3. Choose **"Deploy from Git Repository"**
4. Connect your GitHub account and select:
   - **Repository**: `prachir9891/Login-System`
   - **Branch**: `main`

### **Step 2: Render Auto-Configuration**
Render will automatically detect `render.yaml` and apply these settings:
- **Name**: `login-system`
- **Runtime**: Node.js
- **Build Command**: `npm run build`
- **Start Command**: `npm start`
- **Health Check**: `/` (root path)

### **Step 3: Add Environment Variables**

In the Render dashboard, go to **Environment** section and add:

| Key | Value | Source |
|-----|-------|--------|
| `NODE_ENV` | `production` | Set by render.yaml |
| `MONGO_URI` | Your MongoDB Atlas URI | Add manually |
| `JWT_SECRET` | Generated by Render | Auto-generated |
| `PORT` | `5035` | Set by render.yaml |
| `GOOGLE_CLIENT_ID` | Your Google OAuth ID | Add manually (optional) |

### **Step 4: Important Environment Variables**

#### MongoDB Atlas Connection String
```
mongodb+srv://username:password@cluster.mongodb.net/login-system?appName=login-register-dashboard
```
**Ensure IP Whitelist** includes Render's IP addresses (or set to `0.0.0.0/0` for development)

#### JWT Secret
- **Option A**: Let Render generate it (recommended) - set `generateValue: true` in render.yaml
- **Option B**: Provide your own secure string (min 32 characters)

#### Google OAuth (Optional)
Get your Google Client ID from [Google Cloud Console](https://console.cloud.google.com)

## 📊 Build & Start Process

### **Build Phase**
```bash
npm run build
# This runs:
# 1. npm install (root)
# 2. npm install --prefix client (client dependencies)
# 3. npm run build --prefix client (build React app)
# 4. npm install --prefix server (server dependencies)
```

### **Start Phase**
```bash
npm start
# This runs: node server/index.js
# Server serves static React files from /client/dist
```

## 🔗 Production Behavior

### Frontend (React)
- Built static files served from `/client/dist`
- All routes fallback to `index.html` for SPA routing
- Runs on the same domain/port as the backend

### Backend (Express)
- Serves frontend static files
- Provides API endpoints at `/api/auth/*`
- Connects to MongoDB Atlas
- Uses JWT for authentication

### Health Check
- Path: `/`
- Returns: React index.html (production mode)
- Ensures Render knows the service is healthy

## 🔍 Monitoring & Logs

After deployment, check:
1. **Logs** tab → View real-time server logs
2. **Metrics** tab → Monitor CPU, memory, and requests
3. **Health** tab → Verify `/` health check status

### Common Issues

| Issue | Solution |
|-------|----------|
| Build fails | Check `npm run build` runs locally without errors |
| App crashes | Check MongoDB URI in environment variables |
| 502 Bad Gateway | Verify health check path `/` is accessible |
| Static files 404 | Ensure React build output is in `/client/dist` |
